# MOCrop 因地智宜决策系统

面向北京市怀柔区琉璃庙镇安洲坝村的乡村振兴/挑战杯路演 MVP。系统围绕“数智种养 + 微旅居”双循环生态产业模式，使用本地演示数据和可解释多目标评分模型，为边际土地输出生态优先、经济优先、农旅融合三类推荐方案。

项目不依赖真实外部 API，不使用登录系统或云服务，可在本地直接演示。

## 功能概览

- 路演首页：标题、副标题、核心指标卡、地块选择、模式选择、权重调节。
- 因地智宜推荐：每个地块输出生态优先、经济优先、农旅融合三类方案。
- 评分拆解：展示生态适配、经济收益、农旅体验、劳动力适配和风险惩罚。
- 收益图表：展示三类方案的投入、收入和净收益。
- 生态雷达图：展示生态、经济、农旅、劳动力和风险控制能力。
- 微旅居测算：测算闲置农宅改造成本、入住率、客单价、年收入、净收入、村集体分成和回收期。
- 年度实施计划：展示从地块建档、生态试种、农旅成型到复制扩面的路径。
- 项目作证：模拟 10 个安洲坝村地块样本，输出全村汇总指标和可行性证明报告。
- Markdown 导出：支持普通决策报告和项目可行性证明报告导出。

## 安装与运行

建议使用已有 conda 环境 `MOCrop`：

```bash
conda activate MOCrop
pip install -r requirements.txt
streamlit run app.py
```

运行测试：

```bash
pytest
```

如果 `data/` 下的 CSV 演示数据缺失，系统会在启动或测试时自动生成本地 demo 数据。

## 演示数据

`data/` 提供 5 类本地 CSV：

- `parcels.csv`：地块面积、坡度、土壤 pH、有机质、日照小时数、水源距离、地块类型、水土流失风险、可用劳动力等。
- `crops.csv`：作物知识库，包括适宜地类、适宜 pH、坡度耐受、水分需求、劳动强度、亩产、价格、投入、固土保水分、农旅分和风险等级等。
- `market_prices.csv`：作物价格、需求评分和价格波动风险。
- `labor.csv`：四季可用劳动力、可用天数和日均工资。
- `homestays.csv`：闲置农宅房间数、改造成本、入住率、客单价、运营成本率和村集体分成比例。

数据为路演演示估算值，用于证明系统逻辑和展示效果，不代表实际经营承诺。

## 核心算法

推荐引擎主体位于 `src/recommender.py`，`mocrop/recommender.py` 保留兼容导出。系统采用可解释多目标评分模型，不调用大模型。

总分公式：

```text
总分 = 生态适配分 × 生态权重
     + 经济收益分 × 经济权重
     + 农旅体验分 × 农旅权重
     + 劳动力适配分 × 劳动力权重
     - 风险惩罚分
```

默认模式权重：

| 模式 | 生态适配 | 经济收益 | 农旅体验 | 劳动力适配 |
|---|---:|---:|---:|---:|
| 生态优先 | 0.45 | 0.20 | 0.15 | 0.20 |
| 经济优先 | 0.20 | 0.45 | 0.15 | 0.20 |
| 农旅融合 | 0.20 | 0.20 | 0.45 | 0.15 |

页面左侧权重滑块会自动归一化，并实时影响当前模式推荐结果。

## 微旅居测算

微旅居测算位于 `mocrop/homestay.py`：

```text
年收入 = 房间数 × 365 × 入住率 × 客单价
运营成本 = 年收入 × 运营成本率
净收入 = 年收入 - 运营成本
村集体分成 = 年收入 × 村集体分成比例
回收期 = 改造成本 / 净收入
```

## 项目作证模块

项目作证模块位于 `src/feasibility.py`，用于比赛路演时证明落地可行性：

- 模拟生成 10 个安洲坝村地块样本。
- 对每个地块生成三类推荐方案。
- 汇总总种植面积、总投入、总收入、总净收益、就业人数、女性/中老年岗位、生态修复均分、农旅体验点数量。
- 生成“项目可行性证明报告”。

报告导出文件名格式：

```text
reports/mocrop_feasibility_report_YYYYMMDD.md
```
