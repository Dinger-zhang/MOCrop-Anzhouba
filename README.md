# MOCrop 因地智宜决策系统

面向北京市怀柔区琉璃庙镇安洲坝村的乡村振兴/挑战杯路演 MVP。系统围绕“数智种养 + 微旅居”双循环生态产业模式，使用本地演示数据和规则评分算法，为边际土地输出生态优先、经济优先、农旅融合三类推荐方案。

本项目不依赖真实外部 API，不使用云服务，适合本地演示和比赛路演。

## 项目背景

安洲坝村位于生态涵养区背景下，山地边际土地、闲置农宅和村民劳动力需要被系统化盘活。MOCrop 的目标是把地块条件、作物特性、市场价格、劳动力供给、生态修复需求和旅居潜力转化为可解释的“一地一策”推荐结果。

系统输出三类策略：

- 生态优先模式：优先推荐冰草、披碱草、文冠果等固土保水和生态修复能力强的作物。
- 经济优先模式：优先推荐黄精、苍术、柴胡、赤松茸、木耳、榛子等高附加值作物。
- 农旅融合模式：优先推荐黄花菜、观赏谷子、药草花境等具备观赏、采摘、研学体验价值的作物。

## 功能清单

- Streamlit 路演首页：项目概览、核心指标卡、模式说明。
- 地块地图：用 Folium 展示安洲坝村示例地块位置和推荐作物。
- 因地智宜推荐：每块地输出生态优先、经济优先、农旅融合三类方案。
- 方案解释：展示推荐作物、推荐理由、预计投入、预计收入、预计净收益、劳动力需求、生态修复评分、农旅体验评分和风险等级。
- 收益图表：使用 Plotly 展示不同地块、不同模式下的收益差异。
- 微旅居测算：计算改造成本、入住率、客单价、年收入、净收入、村集体分成和投资回收期。
- 年度实施计划：展示从地块建档到样板民宿和扩面复制的推进路径。
- Markdown 报告导出：将当前推荐结果和微旅居测算结果导出到 `reports/`。
- Pytest 基础测试：验证推荐算法和微旅居收益函数可运行。

## 安装与运行

建议使用你已有的 conda 环境 `MOCrop`：

```bash
conda activate MOCrop
pip install -r requirements.txt
streamlit run app.py
```

运行后浏览器会打开本地 Streamlit 页面。

## 演示数据

`data/` 中提供 5 类本地 CSV 演示数据：

- `parcels.csv`：地块面积、坡度、土壤 pH、有机质、日照小时数、水源距离、地块类型、水土流失风险、可用劳动力等。
- `crops.csv`：作物知识库，包括适宜地类、适宜 pH、坡度耐受、水分需求、劳动强度、亩产、价格、投入、固土保水分、农旅分和风险等级等。
- `market_prices.csv`：作物价格、需求评分和价格波动风险。
- `labor.csv`：四季可用劳动力、可用天数和日均工资。
- `homestays.csv`：闲置农宅房间数、改造成本、入住率、客单价、运营成本率和村集体分成比例。

数据为路演演示用估算值，便于展示系统能力，不代表真实经营承诺。

## 核心算法

推荐引擎主体位于 `src/recommender.py`，`mocrop/recommender.py` 保留为兼容导出。系统采用可解释多目标评分模型，不调用大模型。

单个作物对单个地块的基础评估包括：

- 生态适配分：地块类型、坡度、土壤 pH、有机质、水源距离、日照和作物水土保持能力。
- 经济收益分：亩均净收益在候选作物中归一化，纳入产量、市场价格、投入成本和劳动力成本。
- 农旅体验分：作物观赏、采摘、研学价值与地块是否靠近道路或民宿资源。
- 劳动力适配分：地块可用劳动力人数与作物劳动强度的匹配程度。
- 风险惩罚分：作物基础风险、水源约束、坡度超限、pH 偏离和生态脆弱性。

总分公式：

```text
总分 = 生态适配分 × 生态权重
     + 经济收益分 × 经济权重
     + 农旅体验分 × 农旅权重
     + 劳动力适配分 × 劳动力权重
     - 风险惩罚分
```

三类模式采用不同权重：

| 模式 | 生态适配 | 经济收益 | 农旅体验 | 劳动力适配 |
|---|---:|---:|---:|---:|
| 生态优先 | 0.45 | 0.20 | 0.15 | 0.20 |
| 经济优先 | 0.20 | 0.45 | 0.15 | 0.20 |
| 农旅融合 | 0.20 | 0.20 | 0.45 | 0.15 |

微旅居测算位于 `mocrop/homestay.py`：

```text
年收入 = 房间数 × 365 × 入住率 × 客单价
运营成本 = 年收入 × 运营成本率
净收入 = 年收入 - 运营成本
村集体分成 = 年收入 × 村集体分成比例
回收期 = 改造成本 / 净收入
```

## 测试

```bash
pytest
```

测试覆盖：

- 每个地块能输出三类推荐方案。
- 推荐结果包含收益、用工、生态评分、农旅评分和风险等级。
- 单个民宿收益测算可运行且为正。
- 批量民宿测算会控制入住率上限。

```text
reports/mocrop_report_20260605_203000.md
```

也可以直接点击“下载当前报告内容”获得 Markdown 文件。
